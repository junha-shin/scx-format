# v0.1.0-alpha.7 — no-install SCX files

Download **scx.py** or **scx.R**, **SHA256SUMS**, and optionally **USAGE.md** from
this release. Verify SHA-256, save the file with your analysis, and use the
Scanpy/Seurat environment you already have. Neither file installs anything.
Both expose `SCX_VERSION = "v0.1.0-alpha.7"`.

## Included

- Same `read_scx`, `write_scx`, `validate_scx`, `to_tsv` API names in Python/R.
- CELL × FEATURE counts, optional normalized expression and typed cell/feature
  metadata. Embeddings and cell graphs are opt-in with `analysis=True` / `TRUE`.
- Matrix TSV / TSV.gz export, ordered ID subsets, output protection, and faster
  pure R rendering from CSR with one text row and no numeric dense matrix.
- Three-platform staged-file tests without SCX installed, checksum/tampering
  checks, corruption/interruption tests and cross-language verification.
- Reproducible PBMC3k results: optimized full R TSV exports 3.64–4.09× faster in
  two local repeats with 0 numeric error and unchanged sizes/plain TSV hashes.
  Peak memory increased by 0.5–21.8 MiB in those observations; historical
  measurements and limitations are in the tagged benchmark documentation.
- Optional Python **0.1.0a7** and native R **0.1.6** packages for users who want
  installed imports/CLI or R's native validation and replacement features.

## Limits and migration

Existing analysis dependencies must be present. Python needs Python >=3.10,
NumPy >=1.24, pandas >=2, SciPy >=1.11.4 and, for object/H5AD I/O, AnnData
>=0.11.4. R needs SeuratObject >=5, Matrix, jsonlite and digest. No new dependency
is installed automatically. Legacy Assay support is under SeuratObject >=5.

One selected assay / feature space. Additional assays/layers, loadings, raw,
arbitrary analysis internals, spatial and multiome remain outside the profile.
Native R cannot represent every pandas dtype; wide integer and numeric-category
limits remain explicit. Keep original analysis objects.

Standalone R creates new directories only and refuses overwrite=TRUE. It checks
single-member gzip CRC/length using scratch disk and publishes a copied SCX
manifest last. R TSV publication is a staged, exclusive, verified copy, not an
atomic reader snapshot; interruption may retain a partial output and lock.
Python retains reference publication/replacement behavior. Existing TSV files
are always refused. Local filesystem tests do not certify network/cloud-sync
filesystems or hostile filesystem changes.

Sparse input validation and CSR conversion need RAM; no out-of-core or fixed
RAM cap is promised. An R CSR conversion can temporarily hold both sparse layouts.
The format remains **0.1-alpha**, metadata schema **1.0**. Existing files remain
readable. Previously unversioned main-branch script copies should be replaced
with these verified files. Alpha.5/alpha.6 assets and tags remain unchanged.

## Reproduce

Follow `USAGE.md` in the release, or the tagged `docs/install.md` and
`docs/release-verification.md`. `verification.json` records the exact commit,
package/script hashes, CI gates, platform checks and public-file validation.
Optional package assets are not prerequisites for the standalone examples.
