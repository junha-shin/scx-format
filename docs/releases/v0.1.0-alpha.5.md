# SCX v0.1.0-alpha.5 — first public alpha

SCX exchanges one single-cell RNA feature space between Seurat and AnnData using
gzipped TSV / Matrix Market files with explicit **CELL × FEATURE** orientation.

| Component | Version |
|---|---|
| Git tag | `v0.1.0-alpha.5` |
| Python scx-format | `0.1.0a5` |
| R scxSeurat | `0.1.3` |
| SCX manifest / metadata schema | `0.1-alpha` / `1.0` |

Alpha.1–alpha.4 were internal development iterations. This is the first public
GitHub prerelease; packages are not published to PyPI or CRAN.

## Install and try

Start with the [combined Python/R installation and conversion guide](https://github.com/junha-shin/scx-format/blob/v0.1.0-alpha.5/docs/getting-started.md).
It provides both Seurat → AnnData and AnnData → Seurat examples, using an explicit
Python interpreter from R.

Downloads:

- `scx_format-0.1.0a5-py3-none-any.whl`: installable Python package.
- `scx_format-0.1.0a5.tar.gz`: Python source distribution.
- `scxSeurat_0.1.3.tar.gz`: installable R source package.
- `SHA256SUMS`: digests for the attached packages and verification report.
- `verification.json`: sanitized installed-package smoke-check evidence.
- `requirements-verified.txt`: full runtime dependency pins from the clean
  Python 3.12 release validation environment.
- GitHub's source archives: the complete tagged repository, guides and examples.

The [verification procedure](https://github.com/junha-shin/scx-format/blob/v0.1.0-alpha.5/docs/release-verification.md)
includes a no-download tiny fixture, full tests, three supported AnnData profiles,
and separate PBMC3k and scaling reproduction. The quickstart compares counts,
normalized values, metadata, embedding, graph and axes through installed Python
and R packages in both directions.

## Included

- Core TSV/Matrix Market I/O, versioned manifest, validator and three CLI commands.
- AnnData adapters and single-assay Seurat Assay/Assay5 support.
- Versioned numeric, boolean, categorical and missing-value metadata preservation.
- Staged output, overwrite protection, explicit replacement, rollback/retained
  backups and file-specific errors with recovery instructions.
- Compatibility, real-data, fault-injection and performance evidence.
- Exact metadata-column restoration after Seurat setters, avoiding automatically
  added QC columns on an AnnData-origin round trip.

See the [changelog](https://github.com/junha-shin/scx-format/blob/v0.1.0-alpha.5/CHANGELOG.md)
for the scope and changes assembled into this first release.

## Known limits

- Single assay / RNA feature space; extra layers, loadings, arbitrary analysis
  settings, identities/history, multiome, spatial and images are outside the profile.
- AnnData requires real counts in `layers['counts']`. Seurat export and import
  both require Python with scx-format. SeuratObject >=5 is required even for
  legacy Assay objects; old Seurat 3/4 runtimes are not qualified.
- Native R rejects unsupported wide integer and categorical types. H5AD can
  change nullable-text or category-label storage dtype. Logical values, missing
  masks and supported category semantics remain checked. See the
  [support matrix](https://github.com/junha-shin/scx-format/blob/v0.1.0-alpha.5/compatibility/README.md).
- In-memory implementation; measurements through 50k cells do not qualify
  million-cell capacity. Historical timings predate the latest safety gates.
- Directory replacement has a brief name gap. Hard interruption can require
  manual recovery; network/cloud-sync filesystems and power-loss durability are
  not certified. See [recovery instructions](https://github.com/junha-shin/scx-format/blob/v0.1.0-alpha.5/docs/safe-io.md).

The format and APIs may evolve during alpha. Keep original analysis objects and
use versioned outputs. Code is MIT licensed; upstream datasets retain their
own attribution and terms.
