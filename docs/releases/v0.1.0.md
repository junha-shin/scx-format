# SCX v0.1.0

First stable SCX utility release. Download scx.py or scx.R and SHA256SUMS;
use your existing Scanpy/AnnData or Seurat environment without installing SCX.

- Existing-object quickstarts: import/source, write_scx, read_scx, to_tsv.
- Counts, optional normalized expression, typed cell/feature metadata;
  opt-in embeddings and cell graphs. CELL x FEATURE on disk.
- Validated writes, protected destinations, TSV/gzip and ordered subsets.
- Actionable first-use help; plain ASCII README policy enforced in CI.
- Python package 0.1.0; optional R package 0.1.7 (retains its existing version sequence).

The on-disk format identifier remains 0.1-alpha and metadata schema 1.0 to keep
existing files readable. Software release 0.1.0 does not rename this identifier.
Historical alpha tags and assets remain available. Detailed tutorials retain
alpha.7 pins; the minimal quickstarts use this stable release.

Supported versions and dependencies are listed in docs/first-use.md and
compatibility/README.md. Extra assays, spatial/multiome and arbitrary analysis
internals are outside the transport profile. Keep the original analysis object.
Standalone R requires a new SCX output directory and refuses replacement;
Python supports explicit replacement. Sparse validation still needs input memory;
dense TSV output may be large. Follow docs/safe-io.md for interrupted outputs.

Reproduce checks from this tag with the CI workflow and instructions in
docs/release-verification.md. Verify downloaded SHA-256 before execution.
