# v0.1.0-alpha.6

Python **0.1.0a6**; R **scxSeurat 0.1.5**; format **0.1-alpha**;
metadata schema **1.0**. This is a GitHub prerelease, not a PyPI/CRAN release.

## Changes

- One installation into an existing scverse/Seurat environment. Compatible
  dependencies are reused; R installs only missing dependencies and uses
  checksum-verified prebuilt packages where supported.
- Unified `read_scx` / `write_scx` in R and Python; R needs no Python.
- Basic default: counts, optional normalized matrix, typed cell/feature metadata.
  Embeddings and cell graphs require `analysis=True` / `analysis=TRUE`.
- Explicit source-layer selection and automatic validation. Staging, locks,
  overwrite protection, rollback and corruption detection remain enabled.
- Dedicated SciPy 1.11.4 profile and R binary-install tests on three OS platforms.

## Migration and limits

**CLI exports now require `--analysis` to include embeddings/graphs.** Legacy
adapter functions retain their full defaults. Existing SCX files remain readable;
there is no format/schema migration. Alpha.5 assets are unchanged.

One feature space / selected assay only. Extra layers, analysis internals,
loadings, spatial and multiome remain outside the profile; retain originals.
R cannot import every pandas dtype (wide integers and numeric categories fail
explicitly). See [support tables](../../compatibility/README.md).

Binary R coverage is limited to R 4.5.x and the platform/architecture listed in
[installation](../install.md). Other environments require a source build.
The checksum list and verification report accompany release assets. Local
filesystem checks do not certify network/cloud-sync filesystem behavior.
Directory replacement briefly removes its final name; interruption can require
[manual recovery](../safe-io.md).

## Reproduce

Follow [installation](../install.md), then the installed-package
[verification procedure](../release-verification.md). CI artifacts retain the
unit, safety, bridge, binary-install and benchmark smoke results. Real PBMC3k
and scaling reports remain separate historical measurements, not new performance
claims for this release.
